# Security

The Swervie MCP server is a public, read-only catalog with two non-destructive
write tools. It holds no user accounts and no credentials.

To report a vulnerability in the hosted endpoint, the interactive shelf (MCP
App), or anything in this repository, email `info@plum-app.com` with
"security" in the subject. Please do not open a public issue for
vulnerabilities. We aim to acknowledge within three business days.

Rate limits, data handling, and the affiliate-link disclosure are documented in
[docs/data-handling.md](docs/data-handling.md).
